OUTBREAK LEDGER 0.5.3

Extract the complete ZIP to a short path, for example C:\OL53.
Double-click START_OUTBREAK_LEDGER.bat inside the extracted application folder.
The existing compatible Python runtime in Local AppData can be reused.

To see your reviewed figures
1. Open Review workspace, then Manage reports. Choose Outbreak workspace.
2. Add reports, or select Load practice reports to work with example data.
3. Open Events and issues and confirm the appropriate event and links.
4. Open Review figures and approve or correct the relevant source figures.
5. Return to Overview or What changed. Select the event.

To display a response note
1. Open Review response evidence and select a statement.
2. Verify its original PDF page and confirm the statement and event link.
3. Choose Write English note for the event and record a reviewer and reason.
4. Open Response updates. Confirmed links between visible notes appear with
   their sources. Use Withdraw note to remove a note from the reader view.

To save a situation brief
1. In Overview, select a confirmed event and, if needed, an area.
2. Click Save one-page brief. The app uses the latest reviewed figures
   for up to four separate reporting series, prioritising national and
   combined-area figures. It includes up to two eligible English notes.
   With an area filter, a note needs an explicit link to that area.
3. In Saved briefs, open the PDF or download the evidence record.
   Use the workspace selector in Manage reports to switch between
   outbreak briefs and practice briefs.

A saved PDF and its evidence record are stored together in local_data.
The evidence record retains the included values, prior comparison figures,
review decisions, original report references and fingerprints for the
configuration and captured evidence. The saved brief reflects the evidence
available at the time it was generated. Save a new brief after later reviews.
Keep the source files and saved briefs together by backing up local_data.

When upgrading an existing v0.5 workspace, stop both application windows
and back up the entire old folder. Copy its entire local_data folder into
the new folder before starting the new copy. Source PDFs are resolved by
their stored hashes. Keep the original copy as a backup. For earlier
versions, see MIGRATION_v05.md.

Practice reports are fictional and require review before reader figures
appear. Previously imported practice reports retain their original
extractions. The cover-line cleanup applies to newly extracted reports.
