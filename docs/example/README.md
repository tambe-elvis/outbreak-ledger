# Review a fictional outbreak briefing

1. **Check the starting figure.** The [original saved brief](01_original.pdf) shows 18 cumulative confirmed cases from the fictional MSP-DEMO report 12. The previous comparable reviewed figure was 16 from report 10. The difference is a net reported change of 2 across those reviewed periods.
2. **Trace the figure and response note.** In the [original evidence record](01_original.json), look for the report name, PDF page, source fingerprint and reviewer. Open [report 12](../../samples/reports/msp_demo_sitrep_12_fr.pdf) to verify the figure, or [agency report 5](../../samples/reports/agency_demo_sitrep_05_en.pdf) to check the original text about the backlog.
3. **Inspect a correction.** The [second saved brief](02_after_correction.pdf) shows 19 after a simulated reviewer correction. The [second evidence record](02_after_correction.json) preserves the original reported value, the corrected value and the reason. The first saved brief still shows 18.

All figures, places and issuers in this walkthrough are fictional. The correction is a scripted example of the review workflow. It does not assert that the source PDF was revised. The PDFs and evidence records were generated by Outbreak Ledger v0.5.3.
